状态：完成。
日期：2026-09（本轮调研）。
约束：只读调研；网络经 127.0.0.1:2085 代理，单 GET ≤1 MB，curl 输出存 /tmp；本文件是唯一新建文件，未改其他文件，未提交 git。

## 0. 结论速览

- NCEI MBBDB 目录共 **3,970 个唯一航次**（2026-09 经 catalog API 分页拉取，来源见 §2）。
- 按归一化航次号比对，**本地已有 91 个**（jamstec 树 11、strict_primary 多波束零头 2、raw_round2/platforms_tree 24、raw_round2/r2r 54；四类互不重叠）。
- **真实增量 3,879 个航次**，原始文件合计约 **1,169,184 个文件 / 43.8 TB**（未去重、含 RAW 类目；逐航次体量见附录）。年份跨度 1970–2025（2 个无年份），主体在 2000s（1,137）与 2010s（1,406）。
- 增量中 **1,671 个航次在 Marine Trackline 目录有同号单波束版本**（其中 910 条本地已持有单波束 track）；Trackline 同号集中在老船（SURVEYOR 134/134、Melville 164/222、Maurice Ewing 140/145 等），2010 年代新船大多多波束独有。

## 2. NCEI MBBDB 航次清单获取

- 文档：`https://www.ngdc.noaa.gov/next-web/docs/guide/catalog.html` §2.6 Multibeam Catalog Service。
- 端点：`https://www.ngdc.noaa.gov/next-catalogs/rest/multibeam/catalog/survey?max=500&offset=<N>`，分页 8 次拉全（offset 0/500/…/3500），每次响应 210–240 KB，共 3,975 条记录（含分页测试重复 5 条），去重 surveyId 后 **3,970 个**。响应含 platform、startTime/endTime、geometry、fileCount、fileSizeSum。
- 原始 JSON 存 `/tmp/mbbdb_survey_*.json`（临时，未入库）。`catalog/surveyid` 端点（纯名单）返回 HTTP 500，未用。
- 复现命令：`for off in 0 500 1000 1500 2000 2500 3000 3500; do curl -sS --proxy http://127.0.0.1:2085 --connect-timeout 10 --max-time 90 -o /tmp/mbbdb_survey_$off.json "https://www.ngdc.noaa.gov/next-catalogs/rest/multibeam/catalog/survey?max=500&offset=$off"; done`

## 4. 增量航次的 Trackline 单波束版本对照

- 对照文件：`ncei/manifests/ncei_catalog_gap_2026-09.parquet`（15,753 行，nc/xyz 两分支各 7,879/7,874，唯一 survey_id 键 7,877 个，均 catalog_present==True）与 `ncei/manifests/trackline_source_manifest.parquet`（7,400 条本地 track）。
- 结果：3,879 个增量航次中 **1,671 个（43%）在 Trackline 目录有同号单波束版本**；其中 **910 条的单波束 track 本地已持有**（trackline_source_manifest 里能对上）。即 761 个航次"Trackline 有单波束但我们连单波束都没下"。
- 分布特征：老船几乎全有单波束同号（SURVEYOR、WHITING、DISCOVERER、CONRAD、THOMAS WASHINGTON、MT. MITCHELL 均 >95%）；2010 年代新船（Sikuliaq、Nautilus、Langseth、OKEANOS）约五到七成有；NANCY FOSTER、Falkor、RONALD B. BIGELOW、HENRY B. BIGELOW 几乎没有（≤5%）。
- 局限：Trackline 对照按归一化 survey_id 精确匹配，未用平台+年份模糊匹配，少量真实同航次（两边编号体系不同者）会漏记。
