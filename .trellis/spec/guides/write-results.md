# Write Research Results

Use [scientific-writing.md](../shared/scientific-writing.md) for manuscripts,
abstracts, captions, and research-facing reports.

Read the available analysis, tables, figures, or cited sources. Draft the
supported finding, evidence, and interpretation. Do not create a new experiment
just to complete a writing template; identify missing evidence when it limits
a requested claim.

Link to existing records as needed. Commands, settings, software versions,
and model checkpoints belong in Methods or reproducibility notes when relevant,
not in place of the scientific finding. No manifest or separate report file
is required by this guide.

A run that only establishes executability does not establish scientific
performance. Task completion does not itself approve a claim for publication.
