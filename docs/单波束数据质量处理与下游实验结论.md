# 单波束数据质量处理与下游实验结论

> 项目路径：`/mnt/data2/00-Data/ship/`
> 日期：2026-09-03
> 目的：用一页纸说清这两周对单波束数据做了什么、发现了什么、现在能用什么、还剩什么决定没做。详细数字在各 step 报告里，本文只做结论性记录。

---

## 1. 为什么做这些

下游项目（`15-swot_feature_physics_bathy`）要用船测水深训练模型。多波束数据质量高但覆盖稀（全球 5°×5° 格子只有 12% 有多波束），单波束几乎全球都有但质量参差。问题：单波束能不能用、怎么用。

## 2. 做了什么

按时间顺序四件事：

1. **查清数据家底**：每条航线的来源、格式、有没有时间戳、水深正负号约定，全部登记。发现所有来源的水深都是"没经过声速、潮汐、吃水改正的原始值"。
2. **给每条航线估偏差**：把单波束航线和多波束重叠的格子找出来，算每条航线整体偏了多少。六区 230 条里 24 条偏得明显（最大的偏了 4,839 米），全球 1,647 条有参照的航线里 83 条启用改正。
3. **首次计算真交叉点**：两条航线的航迹真的交叉时，同一点的水深差是最硬的质量证据。全球共算出 520 万个交叉点，涉及 26 万对航线。
4. **下游做了两轮对照实验**：在六个选定海区，分别用"只用多波束""加原始单波束""加改正后单波束"训练同一个模型，比较预测误差。

## 3. 发现了什么

每个问题一句话答案：

- **单波束直接加进训练有害吗？** 原始的有害（误差 +16.3 米），改正后基本无害（+1.1 米）。说明偏差改正做对了。
- **重力转换场（GGM）当训练约束有用吗？** 没有。只要加上它就全面变差，控制点稀疏时误差甚至从 90 米爆到上千米。暂时不用它。
- **单波束能改善"多波束到不了的地方"的预测吗？** 使用旧六区处置控制表的纯插值试验证明这些点有水深信息，合并六区的误差从只用多波束的 1,841 米降到改正单波束的 731 米，再降到剔除坏航线后的 673 米。此前神经网络试验的分区结果方向不一致，不能单独归因于单波束数据质量；673 米不是新 r2 控制表的验证结果。
- **把交叉点联合起来解每条航线的修正量（国际通行的网络解法），比我们的方法好吗？** 不好。我们的方法留出误差 23.9 米，网络解法 61.6 米。原因：我们每条航线锚定的是成百上千个多波束格子，网络解法每条航线只有几个交叉点可用，噪声被放大。
- **坏航线怎么处理？** 分三类：整体偏移但内部干净的，改正（而不是删除，删了就丢覆盖）；被误改的好航线，撤回改正；内部自相矛盾的（时间戳倒退、交叉点散乱、无有效数据），剔除。六区 247 条里：28 条剔除、10 条改正、8 条撤回、199 条保留、2 条标记待议。

## 4. 现在能用什么

| 产品 | 位置 | 内容 |
|---|---|---|
| 全球航线偏差表 | `ncei/derived/sb_track_bias_global/` | 1,647 条有多波束参照的航线，每条的偏差、是否启用改正、依据 |
| 改正后单波束格子 | `ncei/derived/singlebeam/file_cells_1min_adjusted/` | 1,730 万个格子，每行带偏差值和是否改正的标记 |
| 全球交叉点表 | `ncei/derived/global_sb_crossover_audit/` | 520 万个交叉点，航线两两互查的质量证据 |
| 全球航线质量处置表 | `ncei/derived/sb_track_quality_global/track_quality.parquet` | 每条单波束航线的处置、交叉点误差、质量标记、阈值和理由 |
| 最终单波束格子（r2） | `ncei/derived/singlebeam/file_cells_1min_final_r2/` | 保留全部格子行，应用或撤回航线改正，并写入 `track_disposition` |
| 六区最终控制表 | `ncei/derived/sb_track_bias_1min/controls_mb_sb_final_<tile>.parquet` | 原样保留多波束控制行，单波束只汇总未标为 `reject` 的航线 |
| 全球覆盖图 | `ncei/figures/coverage_global/` | 每个来源一张全球图，修掉了旧图只画西北太平洋造成的误解 |

下游按两层使用：有严格多波束格子的地方使用严格多波束；其他位置读取 `file_cells_1min_final_r2/`，并过滤 `track_disposition != 'reject'`。

没有多波束参照的航线无法估绝对偏差，最终产品保留原值并记录处置依据；`regional_mrar` 数据没有航线顺序和时间，不参与改正；全球交叉点表按海区裁剪时在分块边界上计数会有出入，报告中已说明。

## 5. 还没做的决定

使用旧六区处置控制表的纯插值试验已经回答数据价值问题：在多波束训练点稀少或缺失的区域，单波束提供了有效的水深约束；六区等权合并误差为 1,841 → 731 → 673 米，依次对应只用多波束、加入改正单波束、再排除拒收航线。最后一种优于只做改正，但各区变化方向仍不一致。新 `controls_mb_sb_final_*` 与旧六区处置有差异，尚未重新计算这组插值指标，不能把 673 米当作 r2 的性能数值。

最终检验区尚未打开。是否打开、使用哪些配置和随机种子属于下游任务，本仓库的最终单波束产品不替代该决定。

## 6. 已知的小问题清单

- 时间戳不单调的航线和六区已确认的无有效格子航线在全球质量表中保留证据，并标为 `reject`；
- elt18、elt19 两条航线有大幅偏差且交叉点方向一致，但现有偏差门槛没有启用改正，仍标为 `flag_large_unapplied_bias`；
- 同时有 nc 和 xyz 表示的航线按清单身份选一个来源进入最终产品，不把同一航线重复计算；
- lon058_lat012 海区加入单波束后误差明显变大（+97 米），原因待查。
